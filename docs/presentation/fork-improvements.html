06 Honest data

Unknown is not the same as available

Voi's feed leaves the reserved and available flags empty. The chart reports those vehicles as unknown, in their own series. It never adds them to the available count.

  • Non-defect series in the policy availability chart
  • Niet-defect option and vehicle counts in the Defecte voertuigen filter
  • Non-operational chart for Amersfoort

08 Your own data

Put an operator's CSV on the map

Ruwe data import reads a park_events CSV in the browser and shows it with the point, cluster or heatmap layers. The file does not leave your computer.

  • No limit on file size or number of rows
  • The Periode picker filters the imported rows
  • Comma or semicolon, decimal commas accepted
  • A bad row stops the import and names its line numberNothing is dropped without telling you

  • Mention privacy: the file is read by the browser and never uploaded.
